1. Ziel der Aufgabe

In Aufgabe 3 wird der ChatClient implementiert und mit einer main-Funktion zu einem kleinen Chat-Beispiel verbunden. Zwei Clients verbinden sich mit dem ChatServer und schicken sich Nachrichten.

2. ChatClient – Implementierung

2.1 Code

class ChatClient(
    sn: SimpleNetwork,
    val name: String,
    onData: (endPoint: EndPoint, data: Any) -> Unit = { _, _ -> }
) {

    var id: Int = -1
    private val clientEndPoint: EndPoint?

    init {
        println("========= Start up client $name ========= ")
        clientEndPoint = sn.connect(address,
            object : ConnectionHandler {

                override fun onMsg(endPoint: EndPoint, msg: String) {
                    println("$name: got msg: '$msg'")
                }

                override fun onData(endPoint: EndPoint, data: Any) {
                    println("$name got data: '$data'")
                    when (data) {
                        is AssignId -> {
                            id = data.id
                            println("$name I got the id: '${'$'}{data.id}'")
                        }
                        is SendMessage -> println(
                            "$name I got the message: '${'$'}{data.msg}' " +
                            "from client with id '${'$'}{data.fromId}'"
                        )
                    }
                    onData(endPoint, data)
                }

                override fun onClose(endPoint: EndPoint) {
                    println("$name connection on client side closed")
                }

                override fun onOpen(endPoint: EndPoint) {
                    println("$name connection established.")
                }
            })
    }

    fun sendMessage(toId: Int, msg: String) {
        if (id >= 0) {
            this.sendData(SendMessage(msg, toId, id))
        }
    }

    fun sendData(data: Any) {
        clientEndPoint?.sendData(data)
    }
}

2.2 Erklärung der Konstruktor-Parameter

  • sn: SimpleNetwork – Instanz des simulierten Netzwerks.
  • val name: String – Name des Clients, wird auch geloggt.
  • onData: (EndPoint, Any) -> Unit = { _, _ -> }:
    • Funktions-Typ, vergleichbar mit BiConsumer<EndPoint, Object> in Java.
    • Default-Wert: ein Lambda, das zwei Parameter ignoriert und nichts tut.
    • Damit kann beim Erzeugen des Clients optional zusätzliches Verhalten für eingehende Daten hinzugefügt werden.

2.3 ID-Verwaltung

var id: Int = -1 bedeutet: der Client hat erst einmal keine gültige ID. Sobald der Server eine AssignId-Nachricht schickt, wird die ID gesetzt: 

when (data) {
    is AssignId -> {
        id = data.id
        println("$name I got the id: '${'$'}{data.id}'")
    }
    ...
}

Solange id < 0, sendet sendMessage() keine Chatnachrichten: 

fun sendMessage(toId: Int, msg: String) {
    if (id >= 0) {
        this.sendData(SendMessage(msg, toId, id))
    }
}

2.4 Safe-Call-Operator bei clientEndPoint

clientEndPoint ist vom Typ EndPoint? (nullable), weil connect() im Fehlerfall null liefern kann.

Beim Senden von Daten nutzen wir den Safe-Call-Operator ?.: 

fun sendData(data: Any) {
    clientEndPoint?.sendData(data)
}

Wenn clientEndPoint == null, passiert einfach nichts – es kommt keine NullPointerException.

3. main-Funktion – zwei Clients chatten

3.1 Code

const val address: String = "http://127.0.0.1:80/"

fun main(args: Array<String>) {

    val sn = SimpleNetwork()
    val cs: ChatServer = ChatServer(sn, address)

    val c1 = ChatClient(sn, "CLIENT1")
    val c2 = ChatClient(sn, "CLIENT2") { eP, data ->
        when (data) {
            is SendMessage -> {
                // C2 antwortet automatisch mit "Pong", wenn er eine Nachricht bekommt
                eP.sendData("Pong")
            }
        }
    }

    println("========= Sending data ========= ")
    c1.sendData("Test 1")
    c2.sendData("Test 2")

    c2.sendMessage(1, "Hello, ich bin die ${'$'}{c2.id}, wer bist Du?")
    c1.sendMessage(2, "Hello, ich bin die ${'$'}{c1.id}. Wie geht es Dir?")
}

3.2 Ablauf

  1. SimpleNetwork() erstellt das simulierte Netzwerk.
  2. ChatServer(sn, address) registriert den ChatServer unter der Adresse.
  3. ChatClient(sn, "CLIENT1") und ChatClient(sn, "CLIENT2", ...) verbinden sich:
    • Server vergibt IDs und sendet AssignId.
    • Clients speichern ihre ID in id.
  4. c1.sendData("Test 1") und c2.sendData("Test 2") testen die onData-Verkabelung.
  5. sendMessage-Aufrufe erzeugen SendMessage-Objekte, die der Server zum Ziel-Client routet.
  6. Der zweite Client hat einen eigenen onData-Callback und antwortet mit „Pong“.
